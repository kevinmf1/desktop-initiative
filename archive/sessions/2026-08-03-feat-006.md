`{}`; the assertion was corrected. The first Rust test compile lacked Tokio's macro/runtime test
features; those features were enabled, after which both suites and both harness gates passed.

No live Google/backend credential was available in this standalone frontend repo. The deterministic
tests exercise the security-sensitive native flow shape; end-to-end backend session minting and
credential persistence are explicitly feat-007 scope.
